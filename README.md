# 簽了字就得認

青石集東頭，一個煉氣一層的十九歲少年擺攤代寫契書，一字一靈砂。

他手裡有一本無字簿子，寫下的規矩會自己長出字來。

他替人寫過的每一張紙，都要求有人按手印、有人在場。

這條街上的人，從前沒有人替他們留下什麼。
